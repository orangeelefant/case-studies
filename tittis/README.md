# Case study — Tittis Städ

How [Tittis Städ](https://tittisstad.se) — a Göteborg cleaning company — got a fast booking funnel built and maintained by [Webraketen](https://webraketen.se).

## Stack

- **Astro** for static-fast SEO landing pages
- **Netlify** for hosting + booking-form functions
- **Resend** for transactional emails
- **PostHog** for funnel analytics

## What Tittis Städ does

Hemstäd, flyttstäd, fönsterputs and kontorsstäd in Göteborg with RUT-avdrag. Försäkrad personal, fast pris, online booking.

→ [tittisstad.se](https://tittisstad.se)
