# Case study — Vallawok

How [Vallawok](https://vallawok.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Vallawok

Vallawok är en omtyckt thairestaurang i Linköping sedan 2012, belägen på Wernersgatan 1. Vi lagar äkta thaimat med färska grönsaker — wok, curry, nudlar och klassiker från Thailand. Ät på plats, hämta eller få hemlevererat via Wolt och Foodora. 4,2 av 5 på Google och superrestaurang-betyg hos Foodora.

→ [vallawok.se](https://vallawok.se)

## Stack
- Astro / Next.js
- Netlify / Cloudflare
