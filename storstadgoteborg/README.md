# Case study — Storstäd Göteborg

How [Storstäd Göteborg](https://storstadgoteborg.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Storstäd Göteborg

Storstäd Göteborg är specialiserade på grundlig storstädning och djuprengöring i hela Göteborg — inför flytt eller försäljning, efter renovering eller som återkommande årlig nollställning av hemmet. Vi går rum för rum, tar det som veckostädningen inte hinner, och RUT-avdraget dras direkt på fakturan för privatpersoner.

→ [storstadgoteborg.se](https://storstadgoteborg.se)
