# Case study — Städhjälp Göteborg

How [Städhjälp Göteborg](https://stadhjalpgoteborg.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Städhjälp Göteborg

Städhjälp Göteborg samlar all privat städhjälp på ett ställe — återkommande hemstädning, storstädning, visningsstädning och flyttnära städning i hela Göteborg. RUT-avdraget dras direkt på fakturan och du får ett prisförslag innan du bokar. Beskriv ditt behov så föreslår vi rätt upplägg.

→ [stadhjalpgoteborg.se](https://stadhjalpgoteborg.se)

## Stack
- Astro / Next.js
