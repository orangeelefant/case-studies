# Case study — Hemstäd Göteborg

How [Hemstäd Göteborg](https://hemstadgoteborg.com) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Hemstäd Göteborg

Hemstäd Göteborg erbjuder professionell hemstädning i hela staden — Linnéstaden, Majorna, Hisingen, Centrum och alla övriga stadsdelar. Vi har RUT-avdrag, försäkrad personal och fast pris. Boka enkelt online på under två minuter och få ett rent hem utan krångel.

→ [hemstadgoteborg.com](https://hemstadgoteborg.com)

## Stack
- Astro / Next.js
- Netlify / Cloudflare
- Resend · PostHog
