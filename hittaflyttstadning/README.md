# Case study — Hittaflyttstädning

How [Hittaflyttstädning](https://hittaflyttstadning.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Hittaflyttstädning

Hittaflyttstädning är en oberoende jämförelseguide för flyttstädfirmor i Göteborg. Vi jämför fem firmor efter pris per kvm, besiktningsgaranti och publika omdömen så att du som konsument kan välja rätt — utan provisioner som styr resultaten. Oberoende redaktion driven av Webraketen.

→ [hittaflyttstadning.se](https://hittaflyttstadning.se)

## Stack
- Astro / Next.js
- Netlify / Cloudflare
- Resend · PostHog
