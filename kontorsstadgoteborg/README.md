# Case study — Kontorsstäd Göteborg

How [Kontorsstäd Göteborg](https://kontorsstadgoteborg.se) works online — built and maintained by [Webraketen](https://webraketen.se).

## Om Kontorsstäd Göteborg

Kontorsstäd Göteborg erbjuder professionell kontorsstädning för företag och lokaler i hela Göteborg. Vi tar hand om daglig, vecko- och periodisk storstädning med tydliga rutiner och fast pris exkl. moms. Anpassade upplägg för hybridkontor. Begär offert så gör vi en kort översyn av er lokal.

→ [kontorsstadgoteborg.se](https://kontorsstadgoteborg.se)

## Stack
- Astro / Next.js
- Netlify / Cloudflare
- Resend · PostHog
