# Case study — Städly

How [Städly](https://stadly.nu) became a 4,9★ Google-rated cleaning company in Göteborg with a fast-loading Astro website built and maintained by [Webraketen](https://webraketen.se).

## The brief

Städly needed a sales-funnel website that:
- Loaded fast on mobile (most traffic comes from Google Local Pack on phones)
- Had a 2-minute booking flow
- Surfaced trust signals (Google reviews, Reco badge) above the fold
- Could rank for "städfirma göteborg" + long-tail RUT-relevant queries

## Stack

- **Astro** for content + SEO-critical landing pages
- **Netlify** for hosting + functions for the booking form
- **Cloudflare** in front for DDoS, bot fight, free analytics
- **Resend** for transactional booking emails
- **PostHog** for funnel analytics
- **Google Search Console + GA4** linked for first-party data
- **Schema.org LocalBusiness + AggregateRating** for rich SERP
