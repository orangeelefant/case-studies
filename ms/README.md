# Case study — MS Entreprenad

How [MS Entreprenad](https://msentreprenad.se) — byggentreprenör in Göteborg with 20+ års erfarenhet — runs lead generation through Astro by [Webraketen](https://webraketen.se).

## What MS Entreprenad does

Byggentreprenör i Göteborg med dränering, markarbeten och anläggning. 20+ års erfarenhet i Västra Götaland. Privatpersoner och företag. F-skatt, försäkring, kollektivavtal.

→ [msentreprenad.se](https://msentreprenad.se)

## Stack

- **Astro** for SEO-critical landing pages (per-tjänst breakdowns)
- **Netlify** for hosting + offert-form intake
- **Resend** for transactional confirmations
- Schema.org LocalBusiness for Maps surface
